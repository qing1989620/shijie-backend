# 产品规格 · PRODUCT_SPEC

> 核心价值：**将课堂产生的信息自动转化为练习，将练习暴露出的薄弱点自动转化为复习任务，从而形成真正可循环的学习系统。**
>
> 关键不是"三个 AI 功能"，而是**一条完整的学习数据链**。

## 用户与场景

中学生（及自学者）。课堂是数据的源头：老师讲的每一节课产生转写、笔记、知识点；
课后需要练；练错的、薄弱的需要在"快要忘掉的时候"回来复习。

## 三大一级模块

```
课堂 ──→ 练习 ──→ 巩固
  ↑                    │
  └────── 再次学习 ←────┘
```

### Module 1 课堂
创建课程/课堂 → 浏览器录音 → 实时转写（WebSocket 流式）→ 转写可编辑（乐观并发）
→ 生成课堂笔记（grounded：要点可跳回转写时间戳）→ 提取知识点（canonical 化）
→ **找相关练习（只检索真实题库，绝不生成假题）** → 收藏（立即进入 Module 2）。

### Module 2 练习
个人题库（统一 Question 实体：课堂收藏 / 上传错题 / 题库检索结果共用，关系用 UserQuestion 承载）
→ 错题上传（OCR → 预览 → **人工校对** → 确认入库，content hash 去重）
→ **AI 剖析：知识点树**（prerequisite/core/method/extension 四层角色）
→ 点知识点「找专项练习」（基础/同级/进阶）
→ 随机组题 / 智能组题（偏向做错、薄弱、低保持率、久未练）→ 作答产生 Attempt。

### Module 3 巩固（最高创新优先级）
**每用户 × 每题独立记忆模型**（FSRS-4.5），非固定 1/2/4/7 天。
两层架构：
- **Memory Engine**（科学层）回答"这道题什么时候开始容易忘"——Difficulty / Stability / Retrievability / next due。
- **Review Planner**（产品启发层）回答"今天先复习什么"——记忆风险 + 知识薄弱 + 考试临近 + 逾期 + 每日时间预算装箱。

用户感知层：今日任务（含"为什么现在复习"）、复习日历（来自 ReviewTask 真数据）、
题目详情的记忆曲线（标注"根据学习行为估算"）。冷启动问卷只是 prior，长期行为逐步覆盖。

## 非目标（当前阶段）

- 通用 AI 聊天 / 万能问答（Agent 能力严格收口，见 docs/ai/AGENTS.md）
- 自动生成练习题冒充检索结果（明确禁止）
- 社交、积分排行等外围功能

## 成功标准

`frontend/e2e/full-loop.spec.ts` 全链路 PASS：注册 → 课堂 → 收藏 → 分析 → 练习 → 复习安排 → 完成复习 → 下一次复习。
